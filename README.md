### 2. Customer Churn Analysis
**Tools:** Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook

Explored customer data to investigate churn and retention patterns. Performed data inspection and cleaning, including investigating unparseable `TotalCharges` values associated with customers who had zero tenure.

**Key focus areas:**
- Data quality assessment and cleaning
- Exploratory data analysis
- Customer churn and retention patterns
- Preparing data for further analysis

[**View Project →**](projects/customer-churn-analysis/)

### 3. HR Analytics — Employee Attrition Analysis
**Tools:** Python, Pandas, MySQL, SQL, Tableau

Analyzed employee attrition to identify workforce patterns associated with employees leaving an organization. Used Python for exploratory analysis, SQL for structured comparisons, and Tableau to visualize findings.

**Key focus areas:**
- Attrition by department and job role
- Attrition by overtime, income, and tenure
- Employee satisfaction and work-life balance
- Business travel and combined risk factors
- Data-driven employee retention recommendations

[**View Project →**](projects/hr-analytics-employee-attrition/)
